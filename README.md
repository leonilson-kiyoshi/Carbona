# Carbona
Protótipo feito para Empretec SEBRAE - S. S. Paraíso.

## Hospedagem

Este repositório agora possui um `index.html` na raiz, pronto para ser servido como site estático.

Para hospedar via GitHub Pages:
1. Abra **Settings** do repositório.
2. Vá em **Pages**.
3. Em **Build and deployment**, selecione:
   - **Source**: *Deploy from a branch*
   - **Branch**: branch principal e pasta */ (root)*.
